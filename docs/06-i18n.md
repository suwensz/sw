# 6. 国际化（6 语言）

## 支持语言
| 代码 | 语言 | 文件 |
|------|------|------|
| zh | 简体中文 | `locales/zh.ts` |
| en | English | `locales/en.ts` |
| ja | 日本語 | `locales/ja.ts` |
| ko | 한국어 | `locales/ko.ts` |
| es | Español | `locales/es.ts` |
| fr | Français | `locales/fr.ts` |

## 架构
- Vue I18n v10 Composition API 模式（`legacy: false`）
- 基础文案在 `locales/*.ts`
- V2 扩展模块文案（健康/家人/手表/运营/语音）在 `extensions.ts`，通过 `mergeLocale()` 注入
- 切换语言持久化到 localStorage `qh_locale`，全局即时响应

## 新增文案

### 简单文案
在所有 6 个 `locales/*.ts` 文件中添加对应 key：
```ts
// zh.ts
export default {
  myPage: {
    title: '我的页面',
  },
}
// en.ts
export default {
  myPage: {
    title: 'My Page',
  },
}
```

### 扩展模块文案
在 `extensions.ts` 的 `extensionsByLocale` 中为每个语言添加：
```ts
export const extensionsByLocale = {
  zh: { myModule: { ... } },
  en: { myModule: { ... } },
  // ...其余 4 语言
} as const
```

## 使用方式

### 模板中
```vue
<template>
  <h1>{{ $t('nav.home') }}</h1>
</template>
```

### script setup 中
```ts
const { t } = useI18n()
const msg = t('auth.loginSuccess')
```

### 多语言字段（LocaleText）
```ts
import { tText } from '@/i18n'
import { useAppStore } from '@/stores/app'

const app = useAppStore()
const productName = tText(product.name, app.locale)
```

## 切换语言
```ts
import { setLocale } from '@/i18n'
setLocale('ja')  // 即时切换并持久化
```

## 语音语言映射
`useSpeech` composable 中维护了 i18n locale → speechSynthesis lang 的映射：
```
zh → zh-CN, en → en-US, ja → ja-JP,
ko → ko-KR, es → es-ES, fr → fr-FR
```
