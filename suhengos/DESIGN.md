# DESIGN.md

## 项目与用户画像
- **产品**：素衡OS（Suheng OS）——融合中医健康管理与跨境电商的智能体平台
- **用户**：海外华人、对中医感兴趣的外籍用户、注重健康养生的消费群体
- **核心场景**：通过中医智能体获取健康咨询、体质辨识，系统智能推荐中医药产品并完成跨境购买

## 气质与意象
- **意象锚点**：宋代青瓷与素绢——温润如玉的深青釉色，搭配宣纸般的浅米底，点缀一抹暖金如烛光
- **气质**：东方简约、沉静专业、温润可信。不是古风堆砌，而是现代设计语言下的东方留白
- **场景叙述**：晨光透过竹帘洒在素色药柜上，青瓷茶盏中飘出袅袅药香，安静而有生命力

## Design Tokens

| `--color-primary` | `#1a6b5c` | 深青绿，如青瓷釉色，主色调 |
| `--color-primary-light` | `#2d8b7a` | 青瓷亮面，hover 态 |
| `--color-primary-dark` | `#124d42` | 青瓷暗面，深色背景 |
| `--color-accent` | `#d4a853` | 暖金，如烛光/铜器，点缀与强调 |
| `--color-accent-light` | `#e8c97a` | 浅金，次要点缀 |
| `--color-bg` | `#faf8f3` | 浅米，如宣纸/素绢，页面背景 |
| `--color-bg-card` | `#ffffff` | 卡片纯白 |
| `--color-bg-soft` | `#f2ede3` | 柔米色，分区背景 |
| `--color-text-primary` | `#2c2c2c` | 墨色正文 |
| `--color-text-regular` | `#5a5a5a` | 次要文字 |
| `--color-text-secondary` | `#8c8c8c` | 辅助文字 |
| `--color-border` | `#e8e2d6` | 米色边框 |

### 字体
- **中文**：`"PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`
- **英文/数字**：`"Inter", "Helvetica Neue", Arial, sans-serif`
- **标题字重**：600；正文字重：400；辅助文字：300
- 字体通过 Google Fonts 引入 Noto Sans SC（CN 环境使用 fonts.googleapis.cn）

### 间距
- 基础单位：4px
- 卡片内边距：24px
- 区块间距：32px
- 页面水平内边距：PC 48px / 移动端 16px

### 圆角
- 小圆角（按钮、输入框）：8px
- 中圆角（卡片）：12px
- 大圆角（弹窗、大卡片）：16px
- 胶囊（标签、头像）：999px

### 阴影
- 卡片阴影：`0 2px 12px rgba(26, 107, 92, 0.06)`
- hover 阴影：`0 4px 20px rgba(26, 107, 92, 0.12)`
- 弹层阴影：`0 8px 32px rgba(0, 0, 0, 0.12)`

## 布局与响应式
- 最大内容宽度：1280px，居中
- 导航栏高度：64px（PC）/ 56px（移动端）
- 断点：sm 640px / md 768px / lg 1024px / xl 1280px
- 移动端侧边栏转为抽屉式

## 组件规范
- **按钮**：主按钮深青绿底白字，次按钮米色底深青绿字，文字按钮暖金色
- **输入框**：聚焦时边框变深青绿，无外发光，柔和过渡
- **卡片**：白底、12px 圆角、米色边框、淡青阴影，hover 时阴影加深并微微上浮
- **消息气泡**：用户消息深青绿底白字（右对齐），AI 消息浅米底深青字（左对齐）
- **语言切换**：右上角下拉，地球图标 + 当前语言名

## 动效与交互
- 过渡时长：200ms（基础）/ 300ms（页面切换）
- 缓动：`cubic-bezier(0.4, 0, 0.2, 1)`——温润不生硬
- 卡片 hover：`translateY(-2px)` + 阴影加深
- 页面切换：淡入 + 轻微上移
- 语言切换：全局即时切换，无刷新

## 设计禁忌
- 不要使用科技蓝/紫蓝渐变
- 不要使用高饱和大红大绿
- 不要做古风边框/纹样堆砌
- 不要使用冷灰色调
- 不要让金色大面积使用（仅点缀）
- 不要使用粗糙的阴影和过强的发光效果
