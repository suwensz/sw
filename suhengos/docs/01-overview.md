# 1. 项目概览

## 产品定位

**素衡OS（Suheng OS）** 是一个融合中医健康管理与跨境电商的智能体平台。

- **Web 端**：面向海外华人、对中医感兴趣的外籍用户、注重健康养生的消费群体
- **桌面端（素衡OS）**：面向家庭健康管理场景，提供健康预警桌面通知、智能手表实时监测悬浮窗、开机自启动

## 核心能力

### 中医健康
- 🤖 **中医智能体对话**：多轮对话，支持健康咨询、体质辨识、商品推荐
- 📋 **九种体质测评**：问卷式测评，雷达图结果，调理建议
- 🚨 **健康预警引擎**：融合五运六气、流年气候、三因司天三大中医数据库，结合家人出生年月日精准运算疾病倾向并提前推送
- 👨‍👩‍👧 **家人管理**：多位家人档案，出生年月日参与五运六气运算
- ⌚ **素衡智能手表**：血压/血糖/血脂/尿酸/肌酐/心电图六项指标实时监测

### 跨境电商
- 🛒 **商城**：多语言商品、分类筛选、购物车、多币种结算
- 📊 **竞品分析**：覆盖 Shopee/Lazada/TikTok Shop/Tokopedia/JD/Taobao/Pinduoduo
- 🏭 **供应链**：供应商管理、认证、物流时效
- 📈 **市场需求抓拍**：热搜趋势、供需缺口
- 🎨 **创意工坊**：AI 修图、短视频生成
- 🚀 **自动上架**：6 语标题/描述自动生成，多平台一键发布
